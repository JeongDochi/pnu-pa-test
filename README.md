# 부산대학교 행정학과 진로유형테스트

9문항(A/B) → 3개 축(정책/현장 · 원칙/유연 · 데이터/가치) → 8가지 유형 → 결과지 PNG 자동 생성.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `config.js` | 배포 주소 설정 |
| `og.png` | 링크 공유 시 미리보기 이미지 |
| `data.js` | **질문 · 8가지 유형 문구/진로** (내용 수정은 여기만) |
| `app.js` | 설문 진행 · 점수 계산 |
| `result.js` | 결과지 캔버스 그리기 |
| `bg.png` | 결과지 배경 원본 이미지 (4:5 비율, 1620×2025) |
| `bg-data.js` | `bg.png`를 코드에 내장한 파일 (실제로 쓰이는 건 이쪽) |

## GitHub Pages 배포
1. 저장소 생성 후 이 파일들을 **루트**에 업로드 (폴더째 말고 파일 그대로)
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → Save
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 접속

## 로컬 테스트
`index.html`을 더블클릭해서 열어도 동작합니다.

## 배경 이미지 교체
`bg.png`를 새 이미지로 바꾼 뒤 아래를 실행하면 `bg-data.js`가 다시 만들어집니다.
```
python -c "import base64;open('bg-data.js','w').write(\"const BG_DATA = 'data:image/png;base64,\"+base64.b64encode(open('bg.png','rb').read()).decode()+\"';\")"
```

## 공유 버튼 (결과 화면)
| 버튼 | 동작 |
|---|---|
| 카카오톡 | 결과지 이미지를 **클립보드에 복사** → 카톡 채팅방 입력창에 붙여넣기 (PC: Ctrl+V / 모바일: 입력창 길게 누르기) |
| 인스타 DM | 결과지 이미지를 복사 → 인스타그램 DM 입력창에 붙여넣기 |
| 테스트 링크 | 테스트 주소를 복사 |
| 다른 앱으로 공유하기 | (모바일에서만 표시) 기기 공유창으로 이미지 전송 |

이미지 복사를 지원하지 않는 브라우저(인앱 브라우저 등)에서는 결과지를 자동으로 저장하고 안내 문구를 보여줍니다.
링크 복사에 쓰는 주소는 `config.js` 의 `SITE_URL` 로 지정할 수 있습니다(비워두면 현재 주소).
